# Personal Context Graph

Phase 1 of the Voyage Journey OS keeps four concepts separate: facts, declared preferences, inferences, and corrections.

Rules: inferences never become facts silently; provenance and freshness stay attached to material context; corrections preserve history; consent is explicit and revocable; snapshots are isolated per user; stale, expired, unknown, and rejected states are never silently promoted to current truth.

This slice is provider- and LLM-independent. TiDB persistence, UI, CrewCheck integration, and automated learning remain out of scope until the core contract and tests are stable.
